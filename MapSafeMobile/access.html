Access workflow

Verify before you open

Community access is a controlled path from discovery to evidence, private-key recovery and map display.

The recipient begins with a package that their community permissions allow them to discover. MapSafe checks its local digest against the NextGIS registry and, when supplied, the filename-bound blockchain record before the package reaches the decryption step.

Access · 01

Find an authorised package

Community membership and resource access are separate decisions. NextGIS Web contains distinct resource groups for public keys, anonymised datasets and encrypted packages. ACLs determine what an account can discover and download; OpenPGP recipient selection determines who can decrypt a protected package.

Access · 02

Compare integrity evidence

When a package is selected, MapSafe downloads it, recalculates SHA-256, and compares the result with the digest stored in the NextGIS registry. If a filename-bound blockchain record is supplied, MapSafe also checks the filename and digest pair. A mismatch stops the workflow instead of passing a questionable package to decryption.

This comparison provides evidence about package integrity during transfer. It does not prove the truth of the underlying observation or replace community governance and resource ACLs.

Access · 03

Unlock only what the local key permits

The recipient’s local private key must match one of the OpenPGP recipient envelopes. The passphrase unlocks the protected key only in memory. MapSafe then checks the package’s integrity and the sender’s signature before importing the recovered layer.

After successful decryption, MapSafe clears previously displayed layers, imports the recovered GeoJSON, selects it, and zooms the map to its extent. In this way, the user sees the dataset just recovered rather than a mixture of old and new layers.

Role-specific release: the BMA representative recovers the original in the tested release; Amber receives the anonymised layer authorised for her research purpose.
Access · security

Keep recovery local

Private keys never enter NextGIS Web or the blockchain. Before device replacement, export a protected secret-key backup and keep its passphrase separate from the backup file. Fingerprints should be confirmed through an independent trusted channel, and changed, missing, revoked or removed-member keys should be treated as a reason to stop and review the recipient list.
