MapSafe Mobile

Protect sensitive field observations before they leave the device.

MapSafe Mobile brings spatial anonymisation, recipient-controlled OpenPGP encryption, community exchange, integrity verification and optional blockchain notarisation into the mobile GIS workflow.

Before fieldwork

Start with the community

MapSafe Mobile uses the normal NextGIS account stored by NextGIS Mobile. A community administrator normally prepares the NextGIS Web site, team membership, authentication group and resource access-control lists in a browser. In the field, the user selects that account and community from Security & Sharing.

Important: MapSafe does not create a second login system. Private OpenPGP keys and passphrases remain on the device; only public-key material is published to the community.
1

Prepare the community

Use NextGIS Web to invite members, create or select the authentication group, and assign resource permissions.

2

Choose the account

Open MapSafe, select the connected NextGIS account and choose the community prepared for the field session.

3

Publish public material

Create or import a local OpenPGP identity, publish its public key, and synchronise member keys before sharing.

Optional direct install

Download MapSafe Mobile

For research and field testing, you can install the signed Android release directly instead of using Google Play. Download the APK, keep Google Play Protect enabled, and verify the checksum before installation.
